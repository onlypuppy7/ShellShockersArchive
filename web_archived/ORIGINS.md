Credits identify the collection supplying a file, rather than copyright ownership
or independently verified authorship. Existing Wayback files default to
archive.org. Identical content supplied by multiple collections retains shared
credits. Decoded or processed companions remain labelled as derived copies.

## Public provenance

Dated manifests retain collection credits, recorded capture dates, game paths,
content hashes and reconstruction limits. Public records omit workstation paths,
donor repository locations, Git commit and blob identifiers, author/committer
metadata, internal source filenames and imported README contents.

`origins.json` defines credited sources and shared content credits.
`source_imports.json` contains unique public content credits rather than a donor
repository's observation history. Archive folder suffixes identify recovered
content; they are not donor Git commit identifiers.

ZIP and manifest exports include only provenance for the selected inventory,
including inherited files and relevant shared credits. They do not include the
global source ledger, unrelated collections or donor source documents.

## Dates and reconstruction

Recorded dates are observations, not verified deployment times. Unknown timezones
remain marked. Reported timezone conversions retain their interpretation.

Cachebuster values do not authenticate releases. Primary game-script association
uses verified same-path captures within 24 hours, regardless of query string.
When no such response is available, the HTML inventory records missing game JS.
Unassigned responses remain preserved as standalone captures at their actual
recorded times. Even nearby HTML/JS pairings remain unverified.

Community files can overlay an earlier recovered inventory. Inherited files keep
their own source credits; this does not establish that every file was served
together or that an export will run offline. Production and dev remain distinct,
with dev files under `_dev/`.

Original game payload bytes are preserved. Publication cleanup changes metadata
and archive identifiers only. Detailed donor research and recovery tools remain
local and excluded from Git.
