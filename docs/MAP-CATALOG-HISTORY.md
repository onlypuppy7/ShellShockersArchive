# Maps registered in the archived game scripts

Latest comparison: **1.0.29, 2026-11-17**, `web_archived/1.0.29_2026-11-17_20-05-00_UTC_WorkingStatus_PROD_26897d5e/js/shellshock.js`.

## Scope and interpretation

- Scanned every one of the 1,953 JavaScript files physically stored under `js_archive/` and `web_archived/` (962 distinct contents), including hashed `ss.*.js` bundles, development builds, capture variants, decoded/processed companions, and ignored recovery/asset copies. 1,654 files contain map arrays.
- Decoded 76 encoded game files in memory; 58 same-directory companion catalogs were compared entry for entry. No game bundle was executed; only isolated map-array expressions were evaluated. All game scripts yielded arrays, with zero extraction errors.
- Both early bundled `minMaps`/geometry arrays and later external-file catalogs are included. Previews under `archive-site/`, exported validation copies, and the generated site mirror are excluded.
- “Registered” means present in the catalog, including private-only maps. It does not establish that map assets are available or that a map appears in public matchmaking.
- “Absent” means missing from the latest archived production catalog, not proof of permanent deletion or current live-game status. Seasonal entries can return. Development observations are included in first/last seen; source files identify their channel.
- Dates are the earliest/latest dated archive or filename observations, not guaranteed release or removal dates. Undated recovery copies contribute entries but not dates. Some early filenames have uncertain provenance, and old versions were captured again much later.
- Identity uses map filenames, merging only the explicit same-name filename changes listed below. Display-name changes and capitalization are retained as aliases. Differently named files such as Dirt Too/Dirt 2 and Metamorph/Metamorphosis remain separate.

## Unnamed early maps

Early arrays contain entries whose `name` is the empty string. The audit records **36 distinct serialized unnamed payloads**, with dimensions, SHA-256 fingerprints, source files, and zero-based array indexes in `exported_versions/map-catalog-summary.json`. These are geometry revisions, not 36 proven distinct maps. They cannot be safely assigned invented names or classified as removed named maps. The full literal-array audit retains every unnamed slot.

## Reproduce and inspect evidence

```powershell
node tools/audit_map_catalogs.mjs
python tools/report_map_catalogs.py
```

- `exported_versions/map-catalog-audit.json`: per-script SHA-256, channel, timestamp, literal offset, and every extracted catalog entry.
- `exported_versions/map-catalog-summary.json`: consolidated inventory, source references, and unnamed payload fingerprints.
- `exported_versions/map-catalog-history.csv`: full named inventory with aliases and first/last source paths.
