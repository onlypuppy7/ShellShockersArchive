Provenance notes

Sources, dates and what a recovered version contains.

About the recovered files

Sources. Wayback captures and community collections are credited above. Each file keeps its own source record, including shared credits when collections supplied identical content.

Dates. Capture dates, imported file dates and repository commit dates have different meanings. Unknown timezones are marked; a commit date does not confirm when a version went live.

Recovered versions. Unchanged files can carry forward from earlier captures. Missing files stay missing, and files from different dates are not guaranteed to work together or run offline.

Game sites. Production is shellshock.io; dev is dev.shellshock.io. Dev files stay under _dev/, and an export can contain both.

Decoded copies. Original files are preserved. Decoded and processed companions are labelled separately. Downloads include the source credits and manifests.
